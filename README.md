# Academic-Arsenal 🎓⚙️

**Academic-Arsenal** is an all-in-one, Python-based console application designed to help students easily manage their academic calculations. From computing complex scientific equations to tracking attendance thresholds and evaluating relative grades, this tool brings everything into one unified interface.

## 🚀 Features

### 1. Scientific Calculator (`scientific_calculator.py`)
A comprehensive calculator equipped with:
*   **Basic Arithmetic:** Addition, Subtraction, Multiplication, Division.
*   **Advanced Math:** Logarithms, Power, and Square Roots.
*   **Trigonometry:** Sine, Cosine, and Tangent functions.
*   **Financial Math:** Compound Interest Calculator.
*   **Utility:** Unit Converter (Temperature, Distance, Weight) and Number System Converter (Binary, Decimal, Octal, Hexadecimal).
*   **History:** Keeps track of your session's calculation history.

### 2. Grade Evaluator (`grade_evaluator.py`)
Calculates relative grades based on class averages. 
*   Takes the number of registered courses, scored marks, and class averages as inputs.
*   Evaluates grades dynamically (S, A, B, C, D, F) based on standard relative grading curves.
*   Generates a clean, easy-to-read report card.

### 3. Attendance Evaluator (`attendence_evaluator.py`)
Helps students maintain the mandatory **75% attendance criteria**.
*   Calculates current attendance percentage.
*   Predicts how many upcoming classes you *must* attend to maintain or reach the 75% threshold.
*   Tells you exactly how many classes you can afford to "bunk" if you are safely above the threshold.
*   Warns you if the 75% criteria is mathematically impossible to reach.

## 🛠️️ Installation & Usage

1. **Clone or Download** the repository to your local machine.
2. Ensure you have **Python 3.x** installed.
3. Open your terminal or command prompt and navigate to the project directory.
4. Run the application using the following command:
   ```bash
   python main.py
   ```
5. Follow the interactive on-screen menu to select and use the desired tool.
